#  Луна (Luna) — локальный голосовой ассистент

> Открытая альтернатива корпоративным голосовым ассистентам (Алиса, Alexa, Google Assistant, Siri).
> Работает **полностью локально**, без облака, без слежки, без подписок.

![Version](https://img.shields.io/badge/version-🧲_Магнитосфера_2.1-purple)
![License](https://img.shields.io/badge/license-Apache_2.0-blue)
![Privacy](https://img.shields.io/badge/privacy-локально-green)

##  Философия

- **Локально**: ни один байт не уходит в облако
- **Открыто**: весь код и все модели — с открытыми лицензиями
- **Заменяемо**: любой слой можно заменить на свой (модель, голос, wake word)
- **Безопасно**: опасные действия требуют голосового подтверждения

##  Возможности

### Голосовое взаимодействие
-  Активация по слову «Луна» (собственная ONNX-модель)
-  Прерываемая речь (можно перебить Луну на полуслове)
-  Память и персонализация по говорящему (speaker_id)
-  Таймеры и проактивные напоминания

### Инструменты (32 шт.)
-  Поиск в DuckDuckGo, Википедия
-  Погода, курсы валют ЦБ РФ
-  Калькулятор (понимает "пятнадцать умножить на семь")
-  Списки покупок и задач
-  Управление ПК: приложения, папки, окна, выключение
-  Долговременная память о пользователе
-  Confirmation Manager для опасных действий

### Безопасность
-  Confirmation Manager — выключение, перезагрузка, установка приложений только после голосового "да"
-  Белый список приложений и путей
-  Защищённый автозапуск с паролем (PBKDF2)
-  Быстрые команды обрабатываются без LLM

### Производительность
-  GPU offload (GTX 1650, 85% слоёв на видеокарте)
-  Двухмодельная архитектура: быстрая модель для простых вопросов, мощная для сложных
-  Нативный tool calling через Ollama

##  ИИ-стек (полностью открытый)

Луна построена на открытых моделях и инструментах. Благодарю создателей:

### Модели
| Компонент | Модель | Лицензия | Назначение |
|-----------|--------|----------|-----------|
| **LLM (быстрая)** | [Qwen3 8B](https://huggingface.co/Qwen/Qwen3-8B) | Apache 2.0 | Основной диалог, быстрые вопросы |
| **LLM (умная)** | [Qwen3 14B](https://huggingface.co/Qwen/Qwen3-14B) | Apache 2.0 | Сложные задачи, генерация кода |
| **STT** | [Whisper large-v3](https://github.com/openai/whisper) | MIT | Распознавание русской речи |
| **TTS** | [Piper](https://github.com/rhasspy/piper) | MIT | Синтез русского голоса |
| **Wake word** | Собственная ONNX-модель | Apache 2.0 | Детекция слова "Луна" |

### Инфраструктура
- **[Ollama](https://ollama.com/)** — локальный запуск LLM (MIT)
- **[faster-whisper](https://github.com/SYSTRAN/faster-whisper)** — ускоренный Whisper (MIT)
- **[webrtcvad](https://github.com/wiseman/py-webrtcvad)** — детекция голоса (Apache 2.0)
- **[librosa](https://librosa.org/)** — обработка аудио (ISC)
- **[ONNX Runtime](https://onnxruntime.ai/)** — инференс wake word модели (MIT)

##  Быстрый старт

### Требования
- Linux (тестировалось на Arch Linux / Manjaro)
- Python 3.11+
- GPU с CUDA (опционально, но рекомендуется)
- Микрофон и динамики

### Установка

```bash
# Клонируем репозиторий
git clone https://github.com/sdlinerweqpfik/luna.git
cd luna

# Создаём виртуальное окружение
python -m venv secretary-venv
source secretary-venv/bin/activate

# Устанавливаем Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Загружаем модели
ollama pull qwen3:8b
ollama pull qwen3:14b

# Устанавливаем зависимости Python
pip install -r requirements.txt

# Системные пакеты (Arch Linux)
sudo pacman -S wmctrl xdotool thunar piper
